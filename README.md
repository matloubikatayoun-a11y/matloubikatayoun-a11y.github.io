# Katayoun Matloubi, PhD

Personal academic website: https://katayounmatloubi.com

English, French, Persian. Static HTML, hosted on GitHub Pages.

## Structure (since Nov 25, 2026)

- English site: `index.html` plus one folder per page — `research/`, `publications/`,
  `teaching/`, `talks/`, `fellowships/`, `news/`, `cv/`, `contact/`.
  Shared styles and scripts: `assets/css/site.css`, `assets/js/site.js`; photos in `assets/img/`.
- French and Persian sites: `fr/` and `fa/`, with the same nine pages and folder names as the English site
  (Persian is right-to-left). The language switcher in the header opens the same page in another language.
- The previous homepages (v28) are kept at `classic/`, `classic/fr/` and `classic/fa/` (hidden from search engines).
- Library, museum and campus photographs are from Wikimedia Commons (CC BY, CC BY-SA, CC0
  or public domain) and are credited, with their licence, under each image. Keep those credits.
